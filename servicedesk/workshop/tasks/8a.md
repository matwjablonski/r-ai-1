## Zadanie 8A. Lokalny gate

- Na osobnej gałęzi wprowadź odwracalny błąd typu lub jeden celowo nieprzechodzący test w frontendzie.
- Uruchom `npm run lint`, `npm run typecheck` i `npm test` w `servicedesk/frontend/`. Zapisz, która kontrola wykryła błąd.
- Popraw błąd, ponów kontrole i zanotuj wyniki oraz ograniczenia w `workshop/notes/8a.md`.

**Wynik:** Istnieje dowód błędu i przejścia po poprawce.
