# Przydatne narzędzia

Narzędzia do samodzielnego wypróbowania po warsztacie. Nie są wymagane do wykonania ćwiczeń.

- [Orca](https://orca.dev/) — środowisko do uruchamiania kilku agentów programistycznych równolegle, z osobnym Git worktree dla każdego zadania.
- [Conductor](https://www.conductor.build/) — środowisko do pracy z agentami programistycznymi w odizolowanych przestrzeniach, także zespołowo.
- [Emdash](https://emdash.com/) — platforma do uruchamiania i koordynowania agentów programistycznych lokalnie lub w chmurze; dostępna jest też aplikacja Emdash Classic.
- [Superpowers](https://github.com/obra/superpowers) — zestaw umiejętności i przepływ pracy dla agentów, obejmujący planowanie, testowanie, debugowanie i przegląd zmian.
- [Caveman](https://github.com/JuliusBrussee/caveman) — umiejętności i lokalny proxy skracające odpowiedzi oraz wyniki narzędzi, aby ograniczać zużycie tokenów. Przed użyciem warto sprawdzić, czy skrót nie usuwa potrzebnego kontekstu.
